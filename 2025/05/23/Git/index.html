Git

Posted on 2025-05-23 Edited on 2025-07-18

新建分支

  • git checkout -b
  • git fetch origin
  • git checkout -b origin/<远程分支>
  • git push origin

删除分支

  • git branch -d
  • git push origin –delete

提交

  • git add .
  • git commit -m “commit message”
  • git commit -m “标题” -m “内容”

推送远程分支

  • git push
  • git push -u origin

合并分支

  • git merge
  • git merge –no-ff
  • git config –global merge.ff false
  • git config –global –unset merge.ff
  • git merge origin/
  • git merge –abort
  • git commit -F ./.git/MERGE_MSG

撤销

  • git reset –hard origin/
  • git reset –hard HEAD^
  • git reset –hard HEAD~3
